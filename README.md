🌱 Eco Guardian — Game Edukasi & Sosialisasi Lingkungan Berbasis Web
Eco Guardian adalah platform game edukasi dan sosialisasi berbasis web yang dirancang khusus untuk siswa Sekolah Dasar (SD). Aplikasi ini bertujuan membantu anak-anak memahami pentingnya menjaga alam dan ekosistem melalui metode belajar interaktif yang menyenangkan.

✨ Fitur Utama
📚 Materi Pembelajaran Interaktif: Penyajian materi edukasi seputar alam, ekosistem, dan pelestarian lingkungan dengan bahasa yang mudah dipahami siswa SD.
🗂️ Flashcard Edukasi: Kartu belajar visual untuk membantu siswa menghafal dan mengingat istilah penting seputar lingkungan dengan cepat.
🎮 10 Mini-Game Bertema Alam: Sepuluh permainan interaktif yang melatih pemahaman siswa secara langsung melalui simulasi dan tantangan menjaga ekosistem.
📝 Tes & Evaluasi Pemahaman: Kuis atau tes untuk mengukur sejauh mana pemahaman siswa setelah mempelajari materi dan bermain game.
📊 Rekap Data Tes: Halaman pemantauan dan rekapitulasi hasil tes siswa untuk memudahkan evaluasi kegiatan sosialisasi.
⚙️ Kelola Konten (Admin/Pengajar): Fitur manajemen untuk menambah, mengubah, atau menghapus materi, flashcard, serta soal tes sesuai kebutuhan sosialisasi.
🎯 Target Pengguna
Siswa Sekolah Dasar (SD): Sebagai media belajar sekaligus bermain yang interaktif.
Relawan / Mahasiswa / Pengajar: Sebagai media sosialisasi lingkungan yang praktis, menarik, dan terukur.
🚀 Cara Menjalankan Proyek (Lokal)
Clone repositori ini
git clone https://github.com
Masuk ke direktori proyek
cd eco-guardian
Jalankan aplikasi (Sesuaikan dengan teknologi yang Anda gunakan, misalnya buka index.html di browser atau jalankan perintah npm install lalu npm run dev / jalankan melalui XAMPP).
